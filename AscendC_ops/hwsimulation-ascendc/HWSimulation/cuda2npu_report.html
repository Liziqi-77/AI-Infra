一 · 算子功能

逐条路径顺序推进的 Hull-White 短期利率模拟。时间轴不可并行，路径轴完全独立——这是全部并行性的来源。

rate[i][0] = r0
for j in 0 .. MStep-2:
    dt       = accrual[j+1] - accrual[j]
    alpha_k  = 0.5 * ((σ/a)·(1 - exp(-a·t_k)))² + f_k        k = 1, 2
    Variance = 0.5·σ²/a · (1 - exp(-2·a·dt))                  a→0 时退化为 σ²·dt
    Expect   = rate[i][j]·exp(-a·dt) + alpha_2 - alpha_1·exp(-a·dt)
    rate[i][j+1] = Expect + sqrt(Variance) · nrnd[i][j]       i = 路径号
维度CUDA 原实现AscendC 迁移实现
并行映射1 block × 16 thread，一线程一路径按路径轴切分 AIV 核，一核一段连续路径
时间轴线程内 for 循环 9 步核内顺序扫描，逐步向量化（路径轴为向量维）
系数推导每线程重复计算核内向量 Exp/Sqrt 算一次，向量回读复用
数据搬运cudaMemcpy + 全局访存CopyIn → Compute → CopyOut，DataCopyPad 按列拉取，UB 常驻状态
下发次数1 次核函数 + 主/辅拷贝1 次融合下发：torch.ops.npu.hwm(step, hwparams, accrual, f1, f2, nrnd) → rate
数据类型doublefloat32（Ascend 无 fp64 向量通路）

测量口径：NPU 3，msprof.quick.Task_Duration，warmup = 1，repeats = 1；加速比取各用例几何平均（geomean 51.73×）。悬停柱体可查看明细。

如何解读：该算子规模很小（16 × 10），NPath = 16 时耗时已贴近单次下发开销——同机 16 元素逐元素算子基线约 4.3 µs。因此 51.7× 主要来自「10 次下发合并为 1 次」的开销消除，而非算力提升；NPath 扩展实测 16 → 10.2 µs、256 → 12.1 µs、4096 → 28.2 µs，吞吐随规模平缓增长。
