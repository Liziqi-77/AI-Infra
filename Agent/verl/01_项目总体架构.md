## 1. 项目概述

Dkernel 项目的 SFT（Supervised Fine-Tuning）训练框架是一个基于 **FSDP（Fully Sharded Data Parallel）** 的轻量级分布式训练框架，用于对 Qwen3 系列大语言模型进行 Kernel 代码生成任务的监督微调。该框架支持：
- **FSDP 全分片数据并行**：实现大模型在 8GPU 节点上的高效分布式训练
- **Ulysses 序列并行（Sequence Parallelism）**：支持超长序列（18K+ tokens）的并行训练
- **梯度检查点（Gradient Checkpointing）**：降低显存占用
- **Remove Padding / Varlen Attention**：支持变长序列的高效训练
- **LoRA 微调**：可选的低秩适配微调
- **Liger Kernel 加速**：高效算子加速
- **Hydra 配置管理**：结构化的 YAML 配置系统

## 3. 核心组件功能划分

### 3.1 启动层（Shell Scripts）
| 文件 | 职责 |
|------|------|
| `8b-coldstart.sh` | Qwen3-8B 模型的 SFT 冷启动训练启动脚本，配置分布式参数，调用 `torchrun` |
| `14b-coldstart.sh` | Qwen3-14B 模型版本，参数与 8B 版本类似 |
| `run.sh` | 本地环境的启动封装，设置 PYTHONPATH 和 WANDB_MODE |

### 3.2 训练入口层（Entry Point）
| 文件 | 职责 |
|------|------|
| `kernel/fsdp_sft_trainer.py` | 轻量级入口，使用 Hydra 加载配置，初始化分布式环境，桥接数据集创建和训练器实例化 |

### 3.3 配置管理层（Configuration）
| 文件 | 职责 |
|------|------|
| `verl_patch/trainer/code/config/sft_trainer.yaml` | SFT 训练的主配置文件，定义数据/模型/优化器/训练器参数 |
| `kernel/config/kernel_trainer.yaml` | Kernel 专用的增强配置，包含多轮对话、奖励模型、算法等配置 |
| `kernel/config/kernel_grading.yaml` | 独立的评估配置，用于离线模型评测 |
| `kernel/config/prompt_config/multi_turn_kernel.yaml` | 多轮 Kernel Agent 对话的 prompt 模板配置 |
| `kernel/constant.py` | 存放 Qwen3 模型的专用 Chat Template 字符串常量 |

### 3.4 核心训练层（Core Training）
| 文件 | 职责 |
|------|------|
| `verl_patch/trainer/code/fsdp_sft_trainer.py` | SFT 训练的核心实现，包含训练器类、损失计算、检查点管理、训练循环等全部逻辑（~611行） |

### 3.5 数据层（Data Pipeline）
| 文件 | 职责 |
|------|------|
| `verl_patch/utils/dataset/sft_dataset.py` | 内存型 SFT 数据集，支持 Parquet 和 HuggingFace datasets 加载，负责 tokenization 和 loss_mask 生成 |

### 3.6 基础设施层（Infrastructure）
| 模块 | 文件 | 职责 |
|------|------|------|
| 配置管理 | `kernel/utils/config_manager.py` | 运行时配置热重载（服务器地址、权重等动态配置） |
| 指标收集 | `kernel/utils/metrics_tracker.py` | 批次处理指标跟踪（成功率、编译率、加速比等） |
| 批次优化 | `kernel/utils/batch_optimizer.py` | 自适应批次大小调整 + 请求去重 |
| 服务器管理 | `kernel/utils/server_manager.py` | 服务器池管理与负载均衡 |
| 运行时接口 | `kernel/utils/runtime_api.py` | FastAPI REST 接口用于运行时服务器管理 |
| 奖励计算 | `kernel/rewards/kernel_reward.py` | 奖励函数入口，批量调用远程 Kernel 评估服务 |
| 奖励客户端 | `kernel/rewards/reward_client.py` | 混合型 HTTP Workers，异步提交-轮询模式 |
| Coverage复用 | `kernel/rewards/coverage_helper.py` | 基于覆盖率指标的拒绝采样（RS）机制 |
| 多轮指标 | `kernel/metrics/kernel_multi_turn_metrics.py` | 多轮对话训练的核心指标计算 |
| 质量分析 | `kernel/metrics/mismatch_quality_metrics.py` | 训练-推理不匹配遮蔽质量分析 |

## 5. 技术栈总览

| 类别 | 技术/库 | 用途 |
|------|---------|------|
| **分布式训练** | PyTorch FSDP2 | 全分片数据并行 |
| **序列并行** | Ulysses (DeepSpeed) | 长序列跨 GPU 切分 |
| **配置管理** | Hydra + OmegaConf | 结构化 YAML 配置 |
| **模型加载** | HuggingFace Transformers | 模型加载与 Chat Template |
| **数据处理** | PyTorch Dataset + DistributedSampler | 分布式数据加载 |
| **数据格式** | Parquet (Pandas / HuggingFace datasets) | 训练数据存储 |
| **注意力实现** | Flash Attention 2 | 高效注意力计算 |
| **梯度优化** | AdamW + Cosine/WSD Scheduler | 优化器与学习率调度 |
| **日志跟踪** | Wandb + Console Logger | 训练监控与可视化 |
| **启动框架** | torchrun (PyTorch Elastic) | 多机多卡分布式启动 |
| **序列处理** | flash_attn.bert_padding | remove_padding / varlen |
| **PEFT** | PEFT (LoRA) | 可选的低秩适配 |
| **算子加速** | Liger Kernel | 高效算子 |
| **Shell编排** | Bash | 分布式环境变量配置 |
