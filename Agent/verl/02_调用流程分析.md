## 2. Shell 启动阶段 (8b-coldstart.sh)

| `LEARNING_RATE` | `2e-5` | 学习率 |
| `SP_SIZE` | `4` | Ulysses 序列并行大小 |
| `TRUNCATION` | `right` | 超长序列截断策略 |

支持17个可覆盖的命令行参数，使用 `--key value` 格式。

### 2.4 运行名生成（L99-L141）
`generate_suffix()` 函数根据命令行参数自动生成唯一的运行名后缀，例如 `_batch256_micro2_lr2e-5_drkernel-coldstart-8k_qwen3-8b-base`。

### 2.5 torchrun 启动（L178-L206）
将 Shell 变量通过 Hydra override 语法传递给 Python 训练进程：
```
torchrun --nproc-per-node $GPUS_PER_NODE \
  --master-addr $MASTER_ADDR \
  --node-rank $NODE_RANK \
  --master-port $MASTER_PORT \
  --nnodes $NNODES -m kernel.fsdp_sft_trainer \
  data.multiturn.enable=True \
  data.train_files=$ACTUAL_DATA_PATH \
  ...
```

**关键覆盖参数**：
- `data.multiturn.enable=True` → 启用多轮对话数据集
- `use_remove_padding=True` → 启用变长序列去填充
- `ulysses_sequence_parallel_size=$SP_SIZE` → 序列并行大小
- `model.strategy=fsdp` → 使用 FSDP 分布策略
- `model.fsdp_config.cpu_offload=True` → CPU 卸载（不卸载参数本身）

## 3. Python 入口阶段 (kernel/fsdp_sft_trainer.py)

### 3.1 main() 函数执行流程

```python
@hydra.main(config_path="../verl_patch/trainer/code/config", config_name="sft_trainer", version_base=None)
def main(config):
    # Step 1: 初始化分布式通信
    local_rank, rank, world_size = initialize_global_process_group()
    
    # Step 2: 构建 FSDP 设备网格
    device_mesh = init_device_mesh(device_type="cuda", mesh_shape=(world_size,), mesh_dim_names=("fsdp",))
    
    # Step 3: 构建 Ulysses 序列并行设备网格
    dp_size = world_size // config.ulysses_sequence_parallel_size
    ulysses_device_mesh = init_device_mesh(
        device_type="cuda", mesh_shape=(dp_size, config.ulysses_sequence_parallel_size), mesh_dim_names=("dp", "sp")
    )
    
    # Step 4: 加载 Tokenizer
    local_model_path = copy_to_local(src=config.model.partial_pretrain, verbose=True)
    tokenizer = hf_tokenizer(local_model_path, trust_remote_code=config.model.trust_remote_code)
    
    # Step 5: 修复 Qwen3 Chat Template（非 Coder 版本）
    if "qwen3" in local_model_path.lower() or "qwen-3" in local_model_path.lower():
        if "coder" not in local_model_path.lower():
            tokenizer.chat_template = QWEN3CHATTEMPLATE
    
    # Step 6: 创建数据集
    train_dataset = create_sft_dataset(config.data.train_files, config.data, tokenizer)
    val_dataset = create_sft_dataset(config.data.val_files, config.data, tokenizer)
    
    # Step 7: 创建训练器并启动训练
    trainer = FSDPSFTTrainer(config=config, device_mesh=device_mesh,
                             ulysses_device_mesh=ulysses_device_mesh,
                             tokenizer=tokenizer, train_dataset=train_dataset, val_dataset=val_dataset)
    trainer.fit()
```

### 3.2 DeviceMesh 拓扑说明
以 8 GPU、SP_SIZE=4 为例：
- **FSDP Mesh**: `(8,)` — 8 个 FSDP rank
- **Ulysses Mesh**: `(2, 4)` — 2 个 DP 组 × 4 个 SP 组
  - DP 组之间：不同数据
  - SP 组内部：相同数据在序列维度分片

```
GPU:  [0] [1] [2] [3] | [4] [5] [6] [7]
DP:    dp0                dp1
SP:    sp0 sp1 sp2 sp3 | sp0 sp1 sp2 sp3
```

### 4.2 批次大小规范化详解

`_normalize_config_bsz()` 是关键的分布式批次规范化：

```
原始: train_batch_size = 64 (全局有效批次)
dp_size = 8 (如果SP=1) 或 dp_size = 2 (如果SP=4, 8GPU)
规范化后: train_batch_size = 64 / dp_size

对于 8GPU 且 SP=1: train_batch_size = 8 (每个GPU的DataLoader批次)
对于 8GPU 且 SP=4: train_batch_size = 32 (每个DP组的DataLoader批次)
```

梯度累积次数 = `normalized_train_batch_size / micro_batch_size_per_gpu`

## 5. 训练主循环 (FSDPSFTTrainer.fit)

```python
def fit(self):
    # Step 1: 初始化 Tracking (Wandb 日志)
    tracking = Tracking(project_name=..., experiment_name=..., default_backend=["console","wandb"])
    
    global_step = 0
    total_training_steps = len(train_dataloader) * total_epochs
    
    # Step 2: 外层 Epoch 循环
    for epoch in range(total_epochs):
        train_sampler.set_epoch(epoch=epoch)  # 每个epoch重新洗牌
        
        # Step 3: 内层 Step 循环
        for data in tqdm(train_dataloader, desc=f"Epoch {epoch+1}/{total_epochs}"):
            global_step += 1
            data = TensorDict(data, batch_size=train_batch_size).cuda()
            
            # Step 4: 执行一步训练
            metric = self.training_step(data)
            
            # Step 5: 日志记录
            tracking.log(data=metric, step=global_step)
            
            # Step 6: 按频率保存检查点
            if save_freq > 0 and global_step % save_freq == 0:
                self.save_checkpoint(step=global_step)
            
            # Step 7: 提前退出检查
            if global_step >= total_training_steps:
                # 最终验证 + 保存检查点
                return
        
        # Step 8: Epoch 结束验证
        for val_data in val_dataloader:
            val_loss = self.validation_step(val_data)
        tracking.log({"val/loss": avg_val_loss}, step=global_step)
        
        # Step 9: Epoch 结束保存检查点
        self.save_checkpoint(step=global_step)
```

## 6. 单步训练详解 (training_step)

```python
def training_step(self, batch: TensorDict):
    # 1. 切换训练模式
    self.fsdp_model.train()
    
    # 2. 清零梯度
    self.optimizer.zero_grad()
    
    # 3. 微批次拆分 + 梯度累积
    micro_batches = batch.split(self.config.data.micro_batch_size_per_gpu)
    n_micro_batches = len(micro_batches)
    step_loss = 0
    
    for micro_batch in micro_batches:
        # 4. 计算损失并反向传播 (每个微批次)
        loss = self._compute_loss_and_backward(batch=micro_batch) / n_micro_batches
        step_loss += loss.item()
    
    # 5. 梯度裁剪
    grad_norm = self.fsdp_model.clip_grad_norm_(max_norm=self.config.optim.clip_grad)
    
    # 6. 安全更新 (跳过非有限梯度)
    if not torch.isfinite(grad_norm):
        self.optimizer.zero_grad()
    else:
        self.optimizer.step()
    
    # 7. 学习率调整
    self.lr_scheduler.step()
    lr = self.lr_scheduler.get_last_lr()[0]
    
    # 8. 跨DP组平均损失
    torch.distributed.all_reduce(step_loss, op=ReduceOp.AVG)
    
    return {"train/loss": step_loss.item(), "train/lr(1e-3)": lr * 1e3}
```

## 7. 损失计算详解 (_compute_loss_and_backward)

### 7.1 标准路径（无序列并行）

```
Step 1: 数据搬移到 GPU
  input_ids, attention_mask, position_ids = batch[...].cuda()

Step 2: 提取 loss_mask
  loss_mask = batch.pop("loss_mask")[:, :-1].reshape(-1).cuda()

Step 3: 标准前向传播 (torch.autocast bf16)
  labels = input_ids[:, 1:].contiguous()
  output = fsdp_model(input_ids, attention_mask, position_ids, use_cache=False)
  logits = output.logits

Step 4: 交叉熵损失
  shift_logits = logits[..., :-1, :].contiguous().view(-1, vocab_size)
  shift_labels = labels.contiguous().view(-1).to(shift_logits.device)
  loss = CrossEntropyLoss(reduction="none")(shift_logits, shift_labels)

Step 5: 应用 loss_mask (只对 response 部分计算损失)
  loss = loss * loss_mask.to(loss.device)

Step 6: 归一化 (按有效 token 数)
  if balance_dp_token:
      all_reduce(valid_token_this_rank)
  loss = sum(loss) / (valid_token_this_rank + 1e-8) * dp_size

Step 7: 反向传播
  loss.backward()
```

### 7.2 序列并行路径（Ulysses）

序列并行路径的关键差异在于前向传播前后的处理：

```
Step 1: Remove Padding
  input_ids_rmpad, indices, ... = unpad_input(input_ids.unsqueeze(-1), attention_mask)
  # 将变长序列中的 padding 移除，保留有效 token

Step 2: Ulysses Pad and Slice
  input_ids_rmpad_sliced, position_ids_rmpad_padded, pad_size = ulysses_pad_and_slice_inputs(
      input_ids_rmpad, position_ids_rmpad, sp_size=ulysses_sp_world_size
  )
  # 将有效 token 在 SP 维度上切分，每个 SP rank 只处理 1/sp_size 的 token
  # pad_size 记录需要补零的长度以使所有 SP rank 的序列等长

Step 3: 准备 labels（roll 并 slice）
  input_ids_rmpad_rolled = torch.roll(input_ids_rmpad, shifts=-1, dims=1)  # 左移1位作为 labels
  input_ids_rmpad_rolled = ulysses_pad_and_slice_inputs(input_ids_rmpad_rolled, None, sp_size)
  input_ids_rmpad_rolled = input_ids_rmpad_rolled.squeeze(0)  # 展平

Step 4: 前向传播 (attention_mask=None，使用 varlen flash attention)
  output = fsdp_model(input_ids=input_ids_rmpad_sliced, attention_mask=None,
                      position_ids=position_ids_rmpad_padded, use_cache=False)

Step 5: 局部损失计算
  logits_rmpad = output.logits.squeeze(0)
  loss = CrossEntropyLoss(reduction="none")(logits_rmpad, input_ids_rmpad_rolled)

Step 6: Gather and Unpad (从所有SP rank汇聚损失)
  loss = gather_outputs_and_unpad(loss, gather_dim=0, unpad_dim=0, padding_size=pad_size)
  # gather: 将所有 SP rank 的损失汇聚到每个 rank
  # unpad: 移除之前补充的 padding
  
Step 7: Pad back to original shape
  full_loss = pad_input(loss.unsqueeze(-1), indices=indices, batch=batch_size, seqlen=seqlen)
  full_loss = full_loss.squeeze(-1)[:, :-1]  # 去掉最后一个 token 的损失

Step 8: 应用 loss_mask + 归一化 + 反向传播 (与标准路径相同)
```

**序列并行的关键假设**（代码注释原文）：
> We have a big assumption here, so we can shard the SAME sequence across SP ranks.
> i.e., each GPU has <1 sequence, and each SP group has 1 sequence.
> 1. All SP ranks will receive the *SAME* batch
> 2. Different SP groups will receive *DIFFERENT* batches

## 8. 检查点保存流程

```python
def save_checkpoint(self, step):
    # 1. 配置 FullStateDict 收集模式
    cfg = FullStateDictConfig(offload_to_cpu=True, rank0_only=True)
    
    # 2. 收集完整的模型状态字典
    with FSDP.state_dict_type(self.fsdp_model, StateDictType.FULL_STATE_DICT, cfg):
        state_dict = self.fsdp_model.state_dict()
    
    # 3. 仅在 rank 0 保存
    path = os.path.join(default_local_dir, f"global_step_{step}")
    if rank == 0:
        os.makedirs(path, exist_ok=True)
        self.model.save_pretrained(path, state_dict=state_dict)  # HuggingFace 格式
        self.tokenizer.save_pretrained(path)
        
        # 4. 可选的上传到 HDFS
        if default_hdfs_dir:
            hdfs_io.copy(src=path, dst=default_hdfs_dir)
    
    # 5. 所有 rank 等待同步
    torch.distributed.barrier()
```
